This is Data Analysis project :- "Customer Shopping Behavior Analysis"

This project analyzes customer shopping behavior to uncover patterns in spending, product preferences, and purchasing trends. The goal is to generate actionable business insights that can help improve marketing strategies, customer retention, and revenue growth.

The analysis is performed using Python in a Jupyter Notebook with libraries such as pandas, NumPy, and matplotlib.

# Business Objectives
1.Identify high-value customers
2.Analyze top-performing product categories
3.Understand purchase trends over time
4.Compare spending behavior of new vs returning customers
5.Discover city-wise and demographic patterns
